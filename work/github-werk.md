# GitHub-werk

Los deze workflow op via `prompts.json` in de root en laad vóór uitvoering alle vereiste gedeelde contracten.

## Doel

Maak een compact overzicht van ontwikkelwerk dat momenteel aandacht verdient in relevante GitHub-repositories.

## Workflow

1. Bepaal welke repositories relevant zijn voor de huidige werkcontext of expliciete vraag van de gebruiker.
2. Haal actieve issues, pull requests en recent werk op dat de huidige prioriteiten materieel kan beïnvloeden.
3. Maak onderscheid tussen `In uitvoering`, `Hierna klaar`, `Geblokkeerd/wachten` en `Backlog`.
4. Geef voorkeur aan werk met expliciete target releases, milestones, blokkades of actuele activiteit boven losstaande open issues.
5. Voeg gerelateerde issue- en PR-informatie samen tot één logisch werkitem wanneer passend.
6. Adviseer één volgende ontwikkelfocus.

## Regels

- Een open issue is niet automatisch actief werk.
- Haal Future/Backlog-werk niet naar voren alleen omdat het recent of interessant is.
- GitHub blijft leidend voor de status van issues en pull requests.
- Wijzig issues, labels, milestones of pull requests niet zonder expliciete instructie van de gebruiker.
