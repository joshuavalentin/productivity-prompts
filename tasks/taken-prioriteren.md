# Taken prioriteren

Los deze workflow op via `prompts.json` in de root en laad vóór uitvoering alle vereiste gedeelde contracten.

## Doel

Prioriteer een set taken op basis van deadlines, afhankelijkheden, externe verplichtingen, actieve werkstatus en realistische capaciteit.

## Workflow

1. Haal de door de gebruiker genoemde taken op of gebruik de aangeleverde set.
2. Behoud expliciete prioriteiten van de gebruiker.
3. Identificeer harde deadlines, blokkades, afhankelijkheden, wachtstatussen en actief werk.
4. Pas `contracts/PRIORITIZATION.md` toe.
5. Groepeer taken wanneer nuttig in `Nu`, `Daarna`, `Later` en `Wachten`.
6. Adviseer welk werk nog niet actief moet worden gemaakt.

## Regels

- Wijzig taakprioriteit of deadlines niet automatisch.
- Maak niet iedere achterstallige taak automatisch hoge prioriteit.
- Geef voorkeur aan een kleine actieve set boven een lange ranglijst.
- Benoem wanneer onvoldoende context betrouwbare prioritering verhindert.
