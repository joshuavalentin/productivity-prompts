# Weekly Review

Resolve this workflow through root `prompts.json` and load every required shared contract before execution.

## Purpose

Review the completed week, identify unresolved commitments, and establish a small set of priorities for the next week.

## Workflow

1. Determine the relevant week boundaries in the user's local timezone.
2. Review completed and unfinished Todoist tasks where available.
3. Review calendar commitments that occurred and upcoming events that require preparation.
4. Review meaningful Gmail follow-ups, replies owed, and waiting states.
5. Review GitHub work that closed, progressed, stalled, or remains active.
6. Identify unfinished commitments without treating every open backlog item as a failure.
7. Separate carry-over work from deliberate backlog.
8. Recommend a small number of next-week priorities.

## Default output

- `Completed` — meaningful outcomes, not an exhaustive activity log.
- `Still open` — commitments that remain actionable.
- `Waiting` — external dependencies.
- `Carry over` — work that should intentionally move into next week.
- `Next week` — normally three primary priorities.
- `Observation` — one concise pattern worth noticing, only when supported by the data.

## Rules

- Do not moralize about unfinished work.
- Do not infer productivity from message count, commit count, or calendar density alone.
- Prefer outcomes over activity volume.
- Keep the review short enough to be usable as a weekly reset.
